# ✍️ Блог (CRUD)

Простий блог з повним CRUD-функціоналом. Написаний на чистому HTML, CSS та JavaScript — без жодних залежностей.

## 🗂 Структура проекту

```
blog/
├── index.html   — розмітка сторінки
├── style.css    — стилі
├── app.js       — вся логіка (CRUD, фільтри, пошук)
└── README.md    — цей файл
```

## 🚀 Як запустити

### Спосіб 1 — Live Server (рекомендовано)
1. Відкрий папку `blog/` у VS Code
2. Встанови розширення **Live Server** (якщо ще не встановлено)
3. Клікни правою кнопкою на `index.html` → **Open with Live Server**

### Спосіб 2 — Просто відкрити файл
1. Двічі клікни на `index.html`
2. Він відкриється у браузері

> 💡 Пости зберігаються у `localStorage` браузера — вони не зникнуть після перезавантаження сторінки.

## ✅ Функціонал

| Дія           | Як зробити                                     |
|---------------|------------------------------------------------|
| **Створити**  | Кнопка «+ Новий пост» → заповнити форму         |
| **Переглянути** | Клікнути на карточку посту                   |
| **Редагувати**| Кнопка «✏️ Редагувати» на карточці              |
| **Видалити**  | Кнопка «🗑 Видалити» → підтвердити               |
| **Фільтр**    | Кнопки категорій вгорі                         |
| **Пошук**     | Поле пошуку (шукає по заголовку та тексту)     |
| **Теги**      | Вводити тег у полі та натискати Enter           |

## 🛠 Розширення для VS Code

- **Prettier** — `esbenp.prettier-vscode` (для форматування коду)
